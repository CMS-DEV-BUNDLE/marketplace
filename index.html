Zero-Slop Engineering

Built Different by Architecture

Not an Electron wrapper around a remote webapp. Rodent is an air-gapped operating shell that runs completely offline with mathematical guarantees.

Total Network Isolation

Every mini-app runs in a dedicated sandboxed WebContentsView bound to a strict default-src 'none' Content Security Policy. Outbound sockets are hard-blocked at the OS and Electron session boundary.

Burrow P2P LAN Transfer

Share credentials, environment files, and keys between workstations across local Wi-Fi via mDNS discovery and sealed asymmetric XChaCha20-Poly1305 envelopes without ever touching a server.

Cryptographic Verification

Every mini-app downloaded from the marketplace is verified against a strict cryptographic SHA-256 digest before extraction. Zip Slip path traversal guards reject any archive containing symlinks or .. paths.

Zero-Data-At-Rest

Sensitive scratchpads, editors, and token decoders execute secure in-memory wipes on tab close and window unload, adhering to strict GDPR, HIPAA, and corporate air-gap compliance.

Live Hot-Reloading

Install and uninstall mini-apps with 1-click while Rodent is running. Newly registered apps immediately hot-mount into custom app://<id>/ protocol routes without requiring shell restarts.

Fluid 768p to 4K UI

Engineered strictly for desktop and laptop environments. Zero dead margins, fluid side-by-side collapsing columns, and native dark/light theme synchronization with the shell.

Marketplace Developer SDK

Build a Mini-App in 60 Seconds

Dev-Toolkit mini-apps are lightweight, air-gapped web applications. Write clean vanilla HTML/JS, declare permissions, and publish to the global marketplace.

apps/<app-id>/manifest.json

Every mini-app declares its entry point, category, window dimensions, and requested permissions.

{ "id": "cron-helper", "name": "Cron Helper", "version": "1.0.0", "description": "Interactive cron expression explainer and schedule builder", "category": "utilities", "icon": "icon.svg", "main": "index.html", "permissions": ["clipboard"], // clipboard, files, vault.read, vault.write "tabs": { "allowMultiple": true, "allowDuplicates": true } }

The 2-PR Contribution Workflow

How new community mini-apps are reviewed, packaged, and published:

1. Create branch: git checkout -b app/my-cool-tool 2. Add files in apps/my-cool-tool/ (manifest.json, index.html, icon.svg) 3. Validate locally: npm run validate 4. Submit PR #1 -> Maintainers merge to master 5. GitHub Actions builds zip archive & publishes SHA-256 digest 6. Submit PR #2 updating marketplace.json -> Merged to master 🎉 Instantly discoverable in all Rodent desktop clients worldwide!
